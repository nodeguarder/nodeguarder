## 4. AI Scraping & Indexing Strategy

### Allow AI Bot Crawling
- **Purpose:** Enable LLM training data, AI model indexing, and organic visibility.
- **robots.txt:** Allow all major AI bots (GPTBot, Claude bot, Gemini bot).
- **Content Strategy:** Provide plain, well-structured text (not behind popoups or JavaScript).

### robots.txt (AI-Friendly)
```
User-agent: GPTBot
Allow: /

User-agent: CCBot
Allow: /

User-agent: anthropic-ai
Allow: /

User-agent: Gpt4Bot
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: *
Allow: /
Disallow: /admin
```

### Content Types for Scraping
1. **Blog Posts** (Markdown, auto-indexed):
   - Technical deep-dives (e.g., "How Regex + LLM Detection Works").
   - Use cases (e.g., "Enterprise DLP for AI Workflows").
   - Security research (e.g., "Top 10 Secrets Leaked to LLMs in 2024").

2. **Public JSON API** (optional, post-MVP):
   - `/api/patterns.json` — Public regex patterns for secret detection (allows security researchers to index).
   - `/api/changelog.json` — Release history, version information.

3. **Structured Text** (not behind popup):
   - All core copy visible on page load (no lazy loading of CTAs).
   - FAQ sections with full Q&A (searchable, indexable).
   - Pricing and feature details (plain text, not images).

### Opt-Out Options (for user privacy)
- Add `<meta name="robots" content="noindex" />` to `/admin*` pages only.
- All public pages: `<meta name="robots" content="index, follow" />`.
